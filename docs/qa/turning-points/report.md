# 過去の決断が返ってくる国内編・世界編

新規選手のイベントは、その選手が会った人、確定した行動、大会資格、期限の来た約束から選ぶ。国内20回で結果が保存される。そこで終了でき、同じ選手で40回まで続けられる。

## 実装

- `src/core/turningPoints.ts` が候補を絞り、予約した後続・大会講評・時期と身体に合う問いを選ぶ。`src/core/turningPointContent.ts` が各場面の本文、選択肢、直後の返事を持つ。開発サーバーの `?story-debug` で候補の選出理由と除外理由を確認できる。
- `src/core/challenge.ts` と `challengeTypes.ts` が、確定した行動、その理由になった決断、関係者、練習場所、費用、次の予定、実際の出場と成績を保存する。作戦は既存の日次計算へ渡る。単発指導は6,000円と2時間、公開練習は3時間を使う。友人との合同練習、週末だけの確認、自主練習は別の行動になる。
- `src/ui/ChallengeApp.tsx` と `ChallengeResults.tsx` が、結果、人物との記録、過去の決断、国内・世界の結末をその履歴から表示する。既存の経歴付きセーブは、それまでの話を旧方式で継続する。経歴導入時の表示・育成・会場の変更は[前回の検証記録](../life-story/report.md)にある。

## 指定ケースの結果

|ケース|確認できたこと|
|---|---|
|A 初期分岐|同じ初回から桐谷のジム、涼と近所のジム、自宅へ分岐。2回目はそれぞれ測定会への誘い、同じ大会を目指す相談、客観的な評価を受ける方法の選択になった。|
|B 支援の成立|2回目に同じ大会を約束 → 3回目に大会を分ける → 4回目に受付から出番まで手伝う → 6回目に涼が荷物を持つと申し出た。申し出を受けると本人が測定会3位。友人との同時出場記録はない。「会場へ行かず、練習後に連絡する」を選んだ比較実行では、このお礼は発生しなかった。実際に同時出場する別ケースも[分岐比較](counterfactuals.json)に記録した。|
|C 環境変更|自宅で記録 → 単発指導 → 公開練習 → 相談した時間帯に宮田のジムへ入会。初回の記録と指導費が後の履歴にも残った。|
|D 同じ大会での違い|涼と始めた選手は16回目に近所のジムから日本グランプリへ。涼が支援し、筋量36.02kgで5位。自宅から始めた選手は26回目に宮田の公開ジムから同大会へ。筋量37.80kg、同行者の記録なしで3位。共に全国へ達した時点でも、使える支援と準備が異なった。|
|E 国内成績と後半|通常の育成計算で作った国内未出場と日本優勝のセーブを、それぞれChromeの読込画面から再開。21回目の出場候補は未出場者が測定会、優勝者が世界大会だった。[画面に表示された候補](continuation-screen.json)|
|F 入口の一致|指導者の2走で全40回の画面記録を比較。選手ID・実時間を除き、経歴、身体を含むキャリア、対戦相手、全決断、大会、結末をまとめたSHA-256が20回・40回でそれぞれ一致。各ログの `at20` と `at40` で照合できる。|
|G 保存・二重確定|3回目の確定ボタンを連打し、結果は1件。5回目に再読み込みし、保存から再開して決断1の回想を開閉。戻った時の状態は同一。各回の記録数が決断番号と一致した。|
|H 結末|全走で国内の結末を表示し、続行後も国内記録が40回時点まで同一であることを照合。国内未出場の選手の結末には申込をせず育成を続けたことが記され、初出場の成績は後半で初めて記録された。|

支援を取りやめる比較では、同じseedのChromeで6回目まで別に操作した。4回目に会場へ行かず練習後に連絡すると、6回目には涼の転勤についての手紙が届いた。同行したという回想も支援へのお礼も出ていない。[当日とその後の画面記録](message-continue.json)

## 再検証と範囲

`npm test` は126件通過。`npm run build` で本番ビルドを確認した。経歴60種類×47都道府県の2,820通りは初期候補を自動検査した。各経歴の40回走破、実機スマートフォンでの操作、人が文章を読んで感じる期待感の評価は未実施。

ローカルの本番プレビューを4187番で起動し、PlaywrightとChromeを利用できる環境で `node scripts/play-turning-points.cjs` に `mentor`、`mentor world`、`friend`、`supported`、`home` をそれぞれ渡すと5走を再現できる。`npx tsx scripts/audit-turning-points.ts` の後に `node scripts/check-domestic-continuation.cjs` を実行すると国内成績の比較を再現できる。最後に `node scripts/verify-turning-points.cjs` が保存済みの5走と続行画面を照合する。

Blenderへの再接続では localhost の9876番が応答しなかった。人体GLBの再造形・再出力と、その新モデルのゲーム内検証は未達。

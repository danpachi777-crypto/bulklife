# BULK LIFE 0.7.2 / 人体 anatomy-v8

支給された `BULK_LIFE_ALL_60_IMAGES.pdf`（64ページ）と、同梱ZIPの `CODEX_PROMPT_JA.txt`、`00_README.txt`、画像一覧CSV、60枚の原本を確認した人物改修。育成ルールの再設計は行っていない。

## 参照の読み方と、実際に変えたもの

- Aは標準骨格、Bは長い手足、Cは広い胸郭・骨盤。DはAの骨格で脂肪の多い状態から変化する経路として制作した。生成画像にある肩の過剰な球形、皮膚のひび割れ、角度ごとの不整合はコピーしていない。
- 首から下を、固定したCC0の連続人体から再構成。以前の累積変形を取り除き、胸郭・胸・肩・腕・背面・脚の発達面を作り直した。16部位の変形は一つの発達面を分担し、重なる領域へ複数の全量変形を加算しない。
- 脂肪を減らす際に肥満用の形を負方向へ外挿していた方式を、新しい正方向の脂肪形状と、別の小さな絞り形状へ分けた。脂肪は腰・腹・胸・顔・腕・脚へ反映する。ポンプは別の小さな変形を使う。
- 骨格は3種類の実際のレストボーンとメッシュを用意。同じ選手の成長・脂肪変化で骨格は変わらない。実装上は**170cm以下でC、182cm以上でB、その間でA**を使う制作上の対応であり、医学的な体格分類ではない。6種類の抽選・身体値・育成上の有利不利は変えていない。
- 腕上げ・肘曲げには、実際のスキニングと体積を保つ参照変形との差を通常のモーフとして焼いた。B/Cの座位・立ち上がりは、足・手の接触を合わせてIKを骨アニメーションへ焼き込み、ゲームに制約オブジェクトを持ち込まない。
- 座位の手は、実際に変化した太ももの表面から接触位置を測って補正。さらに実際のゲーム用ベンチとの接触用形状を3段階の高さで用意し、身長・臀部/脚の発達・脂肪に応じて使う。足の位置を動かして座面へ合わせる処理ではない。
- 顔は目の周囲・頬・鼻翼・唇・顎の面を調整。眼の大きさや人物の特徴を変えず、虹彩の細部・周縁、瞳孔の奥行き、眉の毛流れを制作した。まばたき・視線制御を維持。
- 髪は短髪一種類を優先。側面と頭頂の量、毛流れ、下地、短い毛束、前縁を調整。後頭部の別色の面、表面へ出た下地、裏返った毛束の面を修正。
- タンクトップを現在の身体に再フィット。襟・袖ぐりを曲線として整え、厚い縁を1.4mm厚・3mm幅の縫い代へ作り直した。身体と衣装に同じ変形を接続し、座位用の小さなしわを残した。通常のショーツと身体確認用ショーツは別のまま。
- 高筋量の2体比較で見つかった、身体確認用ショーツ側面の肌の突き抜けも修正。通常ウェアと身体確認用で別の被覆範囲を使い、裸足・見えている腰・下腿を残す。全皮膚の元データを削らず、衣装で完全に覆われる三角形だけを描画から外す。制作ファイルにも対応するプレビュー用マスクを残した。

## 見た目へ反映されない原因として確認したこと

1. 旧作は複数回の局所的な変形が重なり、高筋量で胸や脇に段差が出ていた。書き出し日時だけの問題ではなく、実際の形状に原因があった。
2. Blenderの髪の乗算ノードの色がglTFの色係数に残らなかった。埋め込まれたPNGの実画素とBlenderの画素を照合し、標準glTFの `baseColorFactor` に係数を保持した。ゲーム側だけで別の色へ塗り直してはいない。
3. 髪の内側の面が外側へ出て四角い色むらを作っていた。下地の位置と、毛束の外向きの面を修正した。
   書き出し後に残る黒い三角は透明処理の不一致も影響していたため、配信GLBをゲームと同じ `MASK / 0.18` に統一。旧GLBの比較にもゲームと同じカットアウトを適用し、描画条件をそろえる。
4. v8制作中の再読込確認では、肌を焼く際に衣装用の非表示マスクが効き、足と隠れた太もものUVが黒くなる問題を発見。全身を焼き直し、両領域の画素を検査した。原本テクスチャを上書きしていない。
5. 身長ごとの座面との食い込みは、実際の骨変形とベンチの寸法を計算して検出した。接触形状の有効/無効と接地の値は `runtime-geometry-audit.json` に記録する。

## 画像と検証の区別

- [60方向と修正前後の比較](index.html)：左が支給された原本、右が**書き出した実際のゲーム用GLBを再読み込みして撮影した3D**。元のPNG60枚のSHA256を照合した。
- `before/after-A{1,3,5}-{FRONT,SIDE,BACK}-clay.png`：同じ65mm画角、640×900、同じ中立照明と露出−0.8での単色比較。
- `before/after-face-*`、`*-HAND`、`*-SEATED-*`、`*-WEAR-*`：同じ条件の接写、接触、衣装の比較。
- `exported-*`：実際のGLBを再読込した、顔・高筋量ポーズ・座位・スクワット等の追加確認。
- `before-export-*`：保存してある実際のv7 GLBを同じ条件で再読込した比較。制作データの比較と、書き出した素材の比較を分けている。
- `fixtures.json`：60枚の撮影に使ったゲームのBodyStateと、**ゲームと同じ関数**から得た変形値。写真から体重や体脂肪率を測った値ではない。段階の途中も連続して変形する。
- `runtime-geometry-audit.json`：実際のGLTFLoader・AnimationMixer・SkinnedMeshとベンチを使った接触・接地の計算。CPU上の計算で、ブラウザのFPSを測ったものではない。
- `context-*`：実配信の人物・ジムGLBを配置した座位・通常立位・実際の2体同時表示のBlenderプレビュー。UIやブラウザの照明条件を検証した画像ではない。

形状の確認、変形が有限であること、描画ができること、美術上の完成度は別の評価として扱う。テスト成功を写実品質の証拠にはしていない。
`diagnostic-*` は検討途中の比較で、採用版の品質画像ではない。採用版は比較ページと `exported-captures.json` に記載した画像で確認する。

## セーブと保護

既存のセーブの形式、身体値、乱数、決断回数、大会・育成計算は維持。新規キャリアが記録する作成時の表示版ラベルだけを `anatomy-v8` に更新し、過去のラベルは書き換えない。既存のブラウザのIndexedDBをこの制作作業で操作していない。

`d10b656` に改修前の未コミット作業をチェックポイントとして保護し、`backup/pre-anatomy-v8-20261124` を残した。旧Blender/GLBはバイト単位、元のテキストはGitの改行正規化を考慮して照合。詳細は `preserved-originals.json`。外部素材は既存の固定版CC0素材で、新たな購入・課金は行っていない。支給画像は実装テクスチャやPWAの配信資産へ流用していない。

## 今回の確認環境と制約

- Windows、Intel Core i5-1235U / Iris Xe。Blender 5.3を実際にバックグラウンド実行して複製を編集・描画・書き出した。ライブBlender連携は応答を確認できず、ライブ接続したとは扱っていない。
- このセッションのブラウザ操作環境は `@oai/cua/tinyskyAlt` の読み込みに失敗し、直接のデスクトップ接続も利用できなかった。したがって**今回更新した版のブラウザ目視、スマホ実機、GPU FPS、実測の画面遷移メモリは未検証**。上記GLB画像をブラウザのスクリーンショットと呼ばない。
- 3骨格は固定した制作フレームで、任意の骨格を自由に編集する機能はない。育成は従来の数値から連続的に反映する。
- 座位・主要な腕上げ・肘曲げ・スクワット・極端体型を優先して確認する。全入力・全アニメーション時刻における無貫通を証明したものではない。細い毛先の低画質での見え方は実機確認が必要。
- 最新の集計と最終モデルの内容ハッシュは `verification.json`、HTTPの応答と本番ビルドの参照は `runtime-paths.json` を参照。全121件の自動テストが合格し、本番ビルドも成功。原本60枚に対応する60方向に加え、計95枚を実GLBから描画した。比較ページは原本/3Dの60組と、修正前後・場面の28項目を含む。
- 6人の実際の初期身体と実ベンチを使った計算では、座面との最大ずれは約0.3mm、靴底と床の最大ずれは約0.15mm。これは測った座位と初期条件の結果であり、全時刻・極端体型の物理的な無干渉保証ではない。
- 今回の新版をブラウザで操作して20/40回を再完走したとは報告しない。以前の手動プレイ記録は保持し、今回の変更では既存の計算・保存・進行の自動回帰テストを実行した。

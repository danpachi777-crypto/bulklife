# BULK LIFE 0.7.0

その選択が、身体になる。

「20の決断で日本へ、40の決断で世界へ」。数週間の練習・食事・休養・生活・大会を一つの作戦として確定し、身体と技術、資金、ライバルとの結果を積み重ねる育成シミュレーションです。従来の日次キャリアも別枠で残しています。身体値・成長・費用・審査はゲーム上の推定です。

## 20回・40回の挑戦

日本挑戦は20回・1428日、世界挑戦は40回・2856日。期間は決断番号で固定し、作戦の確認画面へ表示します。作戦を確定する時だけ1回を消費します。比較、編集、取消、身体確認、大会演出、結果、保存では消費しません。国内20回の結果は固定し、同じ選手で追加20回へ進めます。

6種類を各1/6で抽選。コーチの具体的な種目案を比較し、そのまま採用するか、時間・食費・仕事・重点部位・休養を調整します。詳細編集も同じ日次計算と制約です。新モードの最高到達点は架空の「BULK日本グランプリ」「BULKワールドファイナル」。出場条件と順位があり、優勝は保証しません。

決断ホーム、身体、大会、キャリア記録へ移動できます。過去のキャリアから同じ初期条件の別作戦にも挑戦できます。短時間のプレイ目標は20〜30分／40〜60分であり、制限時間はありません。今回のQA込み実測は40回76.2分で、一般プレイヤーの目標時間達成は未確認です。

[ルールと設計](docs/decision-modes.md) / [変更・実際の検証・未完了項目](docs/qa/decisions-v6/report.md) / [人物比較と画面ギャラリー](docs/qa/decisions-v6/gallery.html)。テスト成功と、面白さ・人物の完成品質は分けて報告しています。

## 起動

Node.js 24。Windows PowerShellでは次を実行します。

```powershell
npm.cmd install
npm.cmd run dev
```

ローカルURL: [http://127.0.0.1:5178/](http://127.0.0.1:5178/)。外部へ公開していません。

## スマホから開く

```powershell
npm.cmd run dev:lan
npm.cmd run lan:url
```

PCとスマホを同じWi-Fiへ接続し、`lan:url` が表示したWi-FiのURLをスマホのSafari/Chromeで開きます。2026-11-23確認時のPCは `http://192.168.2.197:5178/`。PCの起動とサーバーを維持してください。スマホ側の127.0.0.1はそのスマホ自身を指します。IPはWi-Fi接続やDHCPで変わることがあります。

タイトルで日本挑戦・世界挑戦を選ぶか、「つづきから」で保存した選手へ戻れます。スマホでは選手と今回の課題を短く表示し、作戦の比較と期間の確定へ進みます。身体の詳細では接写・部位・ポーズ・過去との比較を使えます。通常は縦スクロール、回転したい時だけ「指で回転・ピンチで拡大」を選びます。週間計画と食品・種目の編集は作戦の詳細にあります。

本番用PWAは `npm.cmd run build` で作成されます。`npm.cmd run preview` の `http://localhost:4178/` はPCでの検証用です。スマホのWi-Fi HTTPではオフライン機能を利用できません。HTTPSへ配置した本番ビルドは、初回のオフライン準備後に育成・大会・記録・3Dを使えます。最初に約16.7MBをキャッシュします。外部の出典ページは通信が必要です。更新は「保存して更新」で適用します。今回の改修版での実機オフライン動作は未確認です。

セーブは端末・ブラウザー・URLごとに別で、自動共有しません。挑戦はタイトルの「過去のキャリア」からJSONを書き出し・読み込みできます。読み込みは元の記録を残して別枠へ追加します。従来キャリアは別の保存領域で保護し、新モードへ暗黙変換しません。3Dも元の制作データv2〜v5を残し、作業コピーv6を使用しています。

調査・構成・接続とPWAの条件は [スマホ対応の制作記録](docs/mobile-design.md)、実際の検証範囲は [スマホ版の確認記録](docs/qa/mobile-report.md) を参照。

## 従来キャリアの改修履歴

0.6.0では、設定済みと栄養充足を分け、ホームに目標・不足・献立を表示。相談は練習/食事/休養ごとに確認・採用し、「今日だけ」と「今後も継続」を保存できます。週間実行は表示した曜日別計画を固定で実行し、専用の期間結果へ進みます。日次では翌日のコーチ管理項目を更新します。大会当日の表示、受付とステージ、採点説明、全身記録、並列の身体比較も改修しています。

人物は作業コピーのv5へ更新し、座位の手と前腕、肩の姿勢補正、顔の面、髪の外形、衣服の縁を調整。元v2/v3/v4は保護しています。自動107件と本番ビルドに成功。Chromeで新規開始から14日分、小大会の申込み・停止・出場・結果、保存と再開・JSON移行を確認しました。360/393/430px相当とPC表示も確認済みですが、スマホ実機は未検証です。顔・髪・高筋量時の肩と脇・動作中の布は写実的な完成品質に達していません。[変更・比較画像・実際の検証範囲](docs/qa/consistency-v5/report.md) / [参考資料の確認範囲](docs/qa/consistency-v5/references.md)。

目標・時間・食費から具体的な計画を相談できます。練習・食事・休養ごとに採用でき、詳細で決めた手動の項目は自動で上書きしません。食事カードからプランを選び、一日を実行し、実績と翌日の提案を確認できます。14日分の傾向による食事の見直しは、採用した場合だけ反映します。

人物の口元・目・眉・短髪、独立したトップとショーツ、待機動作、ジムと照明を改良。同じアセットをタイトル・通常画面・身体確認で使用します。元v2/v3の制作ファイルは不変です。

[制作と仕組み](docs/coach-portrait-v4.md) / [比較画像・実際の確認・残る制約](docs/qa/coach-portrait-v4/report.md)。写実的な完成品質、布物理、全姿勢の無衝突や実機性能を保証する改修ではありません。

## 従来キャリアの遊び方

1. 6種類から独立に1/6で抽選された選手を確認し、目標と生活条件を確認して「おすすめの計画で始める」。
2. 「今日」の練習・食事・休養カードを確認。おすすめ設定のまま実行できます。カードから編集し、保存してホームへ戻ります。
3. 「この内容で今日を過ごす」で実績を確認し、翌日の作戦を決めます。
4. 「週間計画」で予定を整え、最大7日をまとめて進められます。大会当日などの必要な判断で停止します。
5. 「キャリア」でジム練習会・地域新人・地方Openへ申込み、出場・講評・再挑戦。全国/国際の既存8大会、資格、世界タイトル、現役続行、引退も同じキャリアで扱います。
6. 「記録」で身体の推移、日次の実績、大会結果と引退の記録を振り返れます。知識と保存管理は補助メニューです。

ローカル3大会はゲーム独自の架空体系です。全国/国際は既存の公式資料を参照した架空シーズンで、JBBF/IFBB国際連盟とNPC Worldwide/IFBB Professional Leagueを分離しています。ローカルの優勝を公式資格へ変換しません。優勝せずに次の目標へ進め、全初期パターンの全大会優勝は保証しません。

## 保存と3D

ブラウザーのIndexedDBへ選手と日次実績を一緒に保存します。設定から全データをJSONへ書き出し、既存選手を消さず別枠に読み込めます。0.1/0.2のセーブを読み込めます。古いモデル参照は保持し、設定で身体値・資格・乱数を変えずに新モデルへ切り替えられます。

3Dは回転、正面/側面/背面、部位のクリック、初日/期間との比較、ポーズ、画像保存、画質切替に対応。v2互換の参照はハッシュ付きv6アセットへ解決し、タイトル・育成・大会・比較で共用します。[v6の実際の変更と制約](docs/qa/decisions-v6/report.md)、元の連続人体・骨格の [v2制作記録](docs/athlete-v2.md) を参照してください。

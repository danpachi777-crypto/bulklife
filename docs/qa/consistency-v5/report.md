# BULK LIFE 0.6.0 — 変更と実プレイ検証

2026-11-22〜23。栄養・計画・表示の不一致を修正し、Chromeで新規開始から14日分、小大会、保存と再開まで実プレイした。検証中に見つかった疲労確認後の計画更新、大会当日の結果説明、ステージの人物の見切れ、比較画面の重なりも修正した。自動107件・型検査・本番ビルドは成功。スマホ実機と写実的な人物の完成品質は未達であり、以下に区別して記録する。

### 食事と成長の再現

同じ新規選手・乱数で「増量目標・手軽な食事・500円」を6初期パターンに適用した。771〜892kcal、たんぱく質51〜55gとなり、不足した案をそのまま実行できる状態を再現した。P2では837kcal・53g、筋質量差は約−0.0055kg。報告された828kcal・53g・−0.007kgの当時のセーブは提供されていないため、完全に同一の状態を再現したとはしない。

ゲームの成長は、刺激・成長余地・回復・たんぱく質充足・エネルギー条件・年齢から増加を計算し、低エネルギーや無刺激等の減少項を別に計算している。不足時は実際の充足とエネルギー条件が低く、減少する場合がある。必ず増えるように数値を変更せず、不足を隠す表示と説明を修正した。結果を食事だけの原因と断定しない。

予算を1200円へ変えた比較も [再現データ](reproduction.json) に保存した。グラム数と、成長計算と同じ上限100%のたんぱく質充足を表示する。エネルギーまたはたんぱく質が目標90%未満なら不足とするゲーム上の目安で、プレイヤー本人への医療・栄養指導ではない。

## UIとキャリア

相談は項目別の入力→未採用案の確認→保存へ分割。食事の相談を開くと練習の大量の設定を先に見せない。チェックを見落として採用されない方式をやめ、触った項目と変更の期間を保存直前へ明示する。手動設定へ切り替わることも表示する。

スマホの行動カードは1列にし、実行は人物と短い計画要約に続く位置へ置く。固定領域へ長い説明を置かない。PCでは人物・作戦・予定の3列を使用する。Chromeの360/393/430 CSS px相当と、1536pxのPC画面で確認した。これは画面サイズのエミュレーションで、実機Safari/Android Chromeではない。

詳細の練習は種目・重量・回数・セットを先に出し、余力・休憩・可動域・優先方針は詳細へ収納。ダンベル片手分と器具の総重量を区別し、入力の刻みを設定。ポージングと有酸素の主な編集場所を休養パネルへまとめた。今日だけの重量提案が他の曜日を変えないこともテストしている。

記録は全身の筋質量・体重・脂肪から見せ、週・月・全期間、日付と数値のある軸を用意。全身の縦軸幅は最低5kgとし、小さな変化を拡大しない。部位別は詳細へ移した。丸めた負のゼロは表示しない。

ローカル大会には費用・日程・生活への影響を確認してから申し込む段階を追加。結果から練習・食事・ポージングへ進む導線、相手の体格・得意評価・過去対戦回数、初出場の記念を追加した。CPUの強さを敗北に合わせて変えていない。全国・国際の目標に必要な次の条件を先に表示し、引退は別項目へ分離した。

## 3Dの変更と比較

元v2/v3/v4の制作ファイルとゲームGLBは変更していない。[原本6ファイルの確認](preserved-originals.json)。新しい編集用は `assets/blender/bulk-life-athlete-v5-work.blend`、ゲーム用は `public/assets/athlete-v5.glb`。ライブBlenderへのMCP接続は300秒でタイムアウトした。既存の応答停止ウィンドウは強制終了せず、インストール済みBlenderの別プロセスで作業用複製を編集・出力した。

## 自動検証と未確認の範囲

- 自動テスト：最終変更後に全107件成功。食事、実績説明、6パターン、固定の週間実行、大会停止、採点、今日だけ/継続の混在、疲労確認後のコーチ更新、IndexedDBとJSONの保存・読み込み、旧セーブ、長期キャリア等を含む。全6パターン・世界大会・引退を今回実ブラウザで全てプレイしたわけではない。
- 最終GLBを実GLTFLoaderで読み込み、5体型×9動作×3時点の135ケースと、立ち上がり37時点を検査済み。肩の補正が腕上げで有効、自然な立位で無効になること、補正の最大変位、形状の有限値、衣服の骨との対応を検査。[ランタイム検査](runtime-report.json)。テクスチャはCPU検査用の寸法スタブで、画質やFPSを証明するものではない。
- 最終変更後の型検査・本番ビルドに成功。PWAは23ファイルを準備。Manifest、アイコン、standalone、明示的な更新を既存実装から維持。v4を参照用に残し、ゲームとキャッシュはv5へ切り替えた。[ビルドとキャッシュの検査](build-report.json)。3D用JavaScriptの約1MBのチャンク警告は残る。
- 既存のユーザー選手は実行していない。Chromeで上記のQA選手と360/393/430px相当・PCを確認。実機iPhone Safari/Android Chrome、物理的なピンチ、FPS/発熱、PWAの実機オフラインは未確認。コンソールに赤い実行エラーは観察せず、Three.Clockの非推奨警告は残る。
- GPU資源は複製した人体のジオメトリ・マテリアル・スケルトンを破棄し、共有器具を誤って破棄しないよう整理した。メモリ増加の実測は未完了。

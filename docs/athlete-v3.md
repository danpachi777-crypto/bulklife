## 人物

- 既存の顔・眼球・まぶた・耳・手足を含む連続人体を使用。新しい顔面スキャンや表情リグの制作ではない。
- CC0の肌色テクスチャをUVに適用し、部位別の粗さと控えめな微細法線を組み合わせた。白飛びの原因だった正規化Uint16頂点色の読み取りも修正した。
- CC0のshort02を頭皮へ追従させた髪型と、既存クロップに毛流れを追加した髪型を選択できる。眉を額へ沿わせ、眼と肌の反射を抑えた。
- 筋肉変形は独立メッシュの拡大ではなく、連続皮膚の頂点変位。肩と腕は骨・腱へ滑らかに移行し、胸は下端に硬い棚ができない広いファン形状へ修正した。筋量と脂肪、パンプの変形は別の値を使う。
- タンクトップを新作し、ショーツの接触・余裕と小さなしわを調整。両方とも同じ18変形と骨格に追従させた。靴・靴下を追加。布の物理シミュレーションではない。
- GymIdle、SeatedPrepare、StandUpを追加。初回の顔上げ、長い呼吸・視線の待機、短い立ち上がりを同じアセットで再生する。音は使っていない。

## 外部素材と条件

[MakeHuman公式システム素材カタログ](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html) と公式CC0アーカイブを実際に確認した。新規購入・課金はない。

取得したのは若い男性の肌、short02、shoes02と必要な対応データ。出典・アーカイブ内パス・各SHA256は `assets/sources/makehuman-system-v3/provenance.json`、CC0本文は同フォルダの `LICENSE.CC0.md`。オリジナル画像・メッシュ・配布時の著作者/ライセンスヘッダーを残した。ゲーム配布向けの派生テクスチャは `assets/blender/portrait-v3-textures`。

## ゲーム統合

タイトル、選手作成、今日、身体詳細で同じ人物を使用。保存があれば育成中の身体・髪型でタイトルに座る。「つづきから」が主操作になる。作成画面では抽選されたタイプと1/6を明記し、外見で育成条件を変更しない。

スマホは大きい全身表示の下に主要3指標、3つの編集操作、日送り、4つのナビを配置。数値で人物を覆わない。回転は明示的に有効化し、終了すると縦スクロールに戻る。身体詳細では3方向、顔の接写、部位選択、比較、ポーズ、ウェアの切替を保持する。カメラが背後へ回った時は壁・備品を非表示にして人物を隠さない。

PCは人物と作戦を左右に配置。設定パネルを閉じると元のホームへ戻る。日次処理の既存ロックに加え、結果画面の最初の500msは次へ進むボタンを無効にし、前画面の2回目のタップが結果を消すのを防ぐ。

軽量画質はDPR1・影なし、標準は最大DPR1.5・1024影。待機描画はスマホ30Hz/PC60Hzを上限とする要求方式で、画面外・バックグラウンド・別の編集シートに隠れた時は停止。これは実機の保証FPSではない。読み込み静止画と進捗、失敗時の代替表示を用意。動きを減らす設定はOS設定と手動設定に対応する。

セーブのモデル識別は互換性のため `athlete-v2` / `regions-v2` のまま、視覚アセットだけ `athlete-v3.glb?revision=...` を使用する。身体値・乱数・実績の移行は不要。古いv1セーブは従来モデルを維持し、既存の設定操作でv2系へ切り替えられる。元v2GLBは保存するがPWAの不要な事前キャッシュからは外した。

## 制作から配信

制作の段階別スクリプトは `assets/blender/*portrait*v3.py`、`refine_athlete_v3.py`、`refine_growth_v3.py`、`refine_pectoral_v3.py`、`gym_room_v3.py`。一回限りの編集ガードがあるため、完成したworkへ全てを再実行しない。

1. workファイルを複製してから編集。
2. 仕上げ後に `polish_portrait_v3.py` のエクスポート処理で人体コレクションのみGLBへ出力。50ボーン、18変形、19クリップを含む。
3. `npm.cmd run assets:portrait` でSHA付きURLを同期。
4. `npm.cmd exec -- tsx scripts/verify-portrait.ts`、型検査、テスト、ビルド。
5. Blenderの `qa_portrait_v3.py` と実ブラウザで形・服・接写・動作を確認。

最終GLBは約7.52MB、50,668三角形。肌は2Kを維持しJPEG化、法線と粗さは512、髪は1K透過にして、途中版約13.9MBから軽量化した。

## 制約

ゲーム用人体の改良であり、実写と見分けがつかない品質ではない。顔の瞬き・表情アニメーション、全関節の補正シェイプ、布シミュレーション、あらゆる体型と全動作の衝突解消は未実装。極端な筋量や深い屈曲では形状の調整余地がある。タイトルの立ち上がりは短い骨格アニメーションとフレーミング変更で、歩いてジムを移動するシーンではない。実績連動の棚・トロフィーは追加していない。

実確認と画像は [確認記録](qa/athlete-v3/report.md) を参照。

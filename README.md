# BULK LIFE 0.3.1

その選択が、身体になる。

選手の練習・食事・休養を決め、身体と技術の変化を確かめ、小さな大会から長いキャリアを歩む育成シミュレーションです。ゲーム内の身体値・成長・費用・審査は架空の推定値です。

## 起動

Node.js 24。Windows PowerShellでは次を実行します。

```powershell
npm.cmd install
npm.cmd run dev
```

ローカルURL: [http://127.0.0.1:5178/](http://127.0.0.1:5178/)。外部へ公開していません。

## スマホから開く

```powershell
npm.cmd run dev:lan
npm.cmd run lan:url
```

PCとスマホを同じWi-Fiへ接続し、`lan:url` が表示したWi-FiのURLをスマホのSafari/Chromeで開きます。今回のPCは `http://192.168.2.197:5178/`。PCの起動とサーバーを維持してください。スマホ側の127.0.0.1はそのスマホ自身を指します。IPはWi-Fi接続やDHCPで変わることがあります。

スマホでは、選手の要約、今日の練習・食事・休養、下部の実行ボタンをまとめています。3Dのタップで身体詳細を開きます。通常は縦スクロール、回転したい時だけ「回転操作を有効にする」を選んでください。週間計画は日ごとの要約から編集できます。

本番用PWAは `npm.cmd run build` で作成されます。`npm.cmd run preview` の `http://localhost:4178/` はPCでの検証用です。スマホのWi-Fi HTTPではオフライン機能を利用できません。HTTPSへ配置した本番ビルドは、初回のオフライン準備後に育成・大会・記録・3Dを使えます。最初に約15.4MBをキャッシュします。外部の出典ページは通信が必要です。更新は「保存して更新」で適用します。

セーブは端末・ブラウザー・URLごとに別で、自動共有しません。PC版からスマホや別のURLへ移る時は「知識・設定」からJSONを書き出し、移動先で読み込んでください。保存の構造と育成・大会のルール、GLB/Blender制作資産は今回変更していません。

調査・構成・接続とPWAの条件は [スマホ対応の制作記録](docs/mobile-design.md)、実際の検証範囲は [スマホ版の確認記録](docs/qa/mobile-report.md) を参照。

## 遊び方

1. 6種類から独立に1/6で抽選された選手を確認し、「この選手で始める」。
2. 「今日」の練習・食事・休養カードを確認。おすすめ設定のまま実行できます。カードから編集し、保存してホームへ戻ります。
3. 「この内容で今日を過ごす」で実績を確認し、翌日の作戦を決めます。
4. 「週間計画」で予定を整え、最大7日をまとめて進められます。大会当日などの必要な判断で停止します。
5. 「キャリア」でジム練習会・地域新人・地方Openへ申込み、出場・講評・再挑戦。全国/国際の既存8大会、資格、世界タイトル、現役続行、引退も同じキャリアで扱います。
6. 「記録」で身体の推移、日次の実績、大会結果と引退の記録を振り返れます。知識と保存管理は補助メニューです。

ローカル3大会はゲーム独自の架空体系です。全国/国際は既存の公式資料を参照した架空シーズンで、JBBF/IFBB国際連盟とNPC Worldwide/IFBB Professional Leagueを分離しています。ローカルの優勝を公式資格へ変換しません。優勝せずに次の目標へ進め、全初期パターンの全大会優勝は保証しません。

## 保存と3D

ブラウザーのIndexedDBへ選手と日次実績を一緒に保存します。設定から全データをJSONへ書き出し、既存選手を消さず別枠に読み込めます。0.1/0.2のセーブを読み込めます。古いモデル参照は保持し、設定で身体値・資格・乱数を変えずに新モデルへ切り替えられます。

3Dは回転、正面/側面/背面、部位のクリック、初日/週次との比較、ポーズ、画像保存、画質切替に対応。新規選手は、Blenderで制作した連続人体のv2を使います。MakeHuman公式CC0資産の出自と、独自の骨格/筋肉/衣装/質感の制作手順は [制作記録](docs/athlete-v2.md) にあります。

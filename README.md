# BULK LIFE 0.2.1

その選択が、身体になる。

Node.js 24。Windows PowerShellで npm.cmd install、npm.cmd run dev。ローカルURLは http://127.0.0.1:5178/ 。外部公開していません。

抽選した選手で開始し、週間計画・24種目・30食品・仕事・睡眠を編集して育成します。大会画面からルートを選び、年度登録、資格取得、申込、遠征、計量、審査へ進みます。JBBF/IFBB国際連盟とNPC Worldwide/IFBB Professional Leagueは別系統です。8大会、CPUの世代交代、世界タイトル後の現役続行、今すぐ引退・最終シーズン、引退記録と新しい選手の開始まで接続しています。

旧0.1の選手は画面の明示的なアップグレードから継続できます。身体・名前・計画・過去の記録は保持します。選手一覧から現役・引退選手を切り替え、設定から全データをJSONで出力・別枠へ読み込めます。

3Dはドラッグで回転、正面・側面・背面で視点を戻します。身体を直接クリックして部位を選択。表示モード、規定ポーズ、練習動作、画質、画像保存があります。

npm.cmd test と npm.cmd run build で検証。[進捗](docs/progress.md)、[仕様原典](docs/game-spec.md)。大会の日程・費用・審査能力係数はゲーム設定です。公式規則の確認範囲は画面と資料に明記しています。

0.2.1では全体プレイ検証で見つかった12件を修正。旧0.2.0の身体・記録は読込だけで変更せず、次の日を進めた状態から計算版0.2.1を記録します。旧0.1は従来どおり明示的な競技機能追加で継続できます。[検証と修正報告](docs/qa/playtest-report-2026-11-19.md)。

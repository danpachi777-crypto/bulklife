# BULK LIFE 国内編・世界編の改修記録

この報告は経歴導入時（物語v1）の検証記録。現在の新規プレイは [物語v2の検証記録](../turning-points/report.md) を参照。

起動はリポジトリで `npm.cmd run dev`。ローカル開発画面は http://127.0.0.1:5178/ 。本番確認は `npm.cmd run build` と `npm.cmd run preview -- --host 127.0.0.1 --port 4187`。公開・デプロイはしていない。変更前の Git コミットは `9299610`。作業ツリーの差分をこの版と比較できる。

## 保存と旧版

IndexedDB の `bulk-life-challenges-v1/runs` を使用。新規挑戦には `origin.version=1`、経歴ID、出生地、育ち、現在地、身近な人物名を保存する。決断ごとの候補ID・確定内容・結果・人物の反応が履歴になる。4回の章内の進度は、確定済みの履歴から復元する。大会の `judging` に新しい架空審査式を記録する。既存の `origin` のない保存は元の候補と旧採点で続く。旧版の4回目の実ファイルを読み取り検査し、5回目の旧候補3案への移行を確認した。新しい国内20回の保存のコピーでもアプリの読み込みから身体の過去比較へ到達した。利用者のブラウザの保存を検証に使っていない。

## プレイ記録

## 確認範囲と未達

- 画面試験とシミュレーションの走破は別々に記録した。指定された過去の「悠真」のセーブそのものは入手していない。旧採点の飽和、勤務の端数表示、転機が資金額順だった原因はコードで確認した。
- 実機スマホのFPS、実機のキーボードや安全領域、人が読む標準20分は未測定。画面幅と自動操作からの推定値で代用していない。
- 人物の経歴には専用の手紙と結末があり、主要エピソードは共有する。全経歴の全選択を個別に走破したわけではない。12種類の連続話の全分岐の読後感、資金の多い初期タイプの長期的な難度には追加のプレイ評価が必要。
- 人物GLB更新前のゲーム表示は anatomy-v8 の標準・長身・幅広モデル。実オブジェクト BL_V2_AthleteBody の高筋量時の胸・肩・脇、脚の立体、座位の掌と膝、BL_V4_Hair の生え際、BL_V4_TrainingTank の張りとしわを今回の更新として合格にはしていない。比較審査と会場表示は今回の実装。旧版で作成された人体の画像を今回の造形変更の証拠には使っていない。
- 参考作品は共有ブラウザとは別の検証用Chromeで4サイトの入口を確認した。1in8b.life は時間設定を操作。他の3作品は入口と選択表示まで。外部への投稿、応募、課金、球団の設立は行っていない。

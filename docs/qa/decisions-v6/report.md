# BULK LIFE 0.7 — 20回・40回の挑戦と人物改修

2026-11-23。作業前 `33ce450`、復元ブランチ `backup/pre-decision-modes-20261123`。コード上の機能、実際に操作した範囲、人物の品質を区別して記録する。

## 遊べる内容と進行

日本挑戦20回、最初から世界挑戦40回、日本終了後に同じ選手で追加20回へ進む構成を実装した。国内最高は架空の **BULK日本グランプリ**、世界最高は **BULKワールドファイナル**。従来の公式制度を参考にしたキャリアとは別モードであり、現実の資格として扱わない。

1回で練習・食品/栄養・睡眠・補助練習・仕事・設備・大会を含む期間作戦を確定する。比較、編集、取消、身体確認、記録、大会演出、保存には回数を使わない。最終回も期間計算と大会結果を処理してからエンディングへ進む。引退は強制しない。

## 育成計算と作戦の意味

既存の `simulateDay`、種目ごとの実施計算、食品の価格・栄養、生活時間、収支、筋質量・脂肪・疲労・回復・動作習熟・ポージングを利用する。能力への固定加算やコーチ専用の成長補正はない。既存エンジンへの変更は大会日の使用時間を渡せる任意の引数が中心で、従来の日次キャリアの既定動作は維持した。

新コーチは具体的な種目・重量・回数・セットを組み立てる。従来の簡略「全身」が全16部位に同一刺激係数を掛ける仕様であることを確認し、新モードの標準にはしなかった。「セット」は種目ごとの実セット数、実行時間は実際の `sessionMinutes` に統一。期間結果に最初/最後の実施種目、重量、回数も残す。

基本案、部位/仕事への投資、大会/技術準備を状態から生成し、該当時は設備投資、過去の対戦相手に合わせた再挑戦、回復案を加える。時間・費用・回復・優先しないことを比較し、同じ候補を調整/自作できる。手動の練習と食事は別々に管理でき、自動調整に戻す場合も明示操作が必要。

自動調整は合意した目的・食費上限・方法内の食品量、能力に応じた負荷、疲労による休養、大会前の休養。目的・設備購入・大会・仕事・有料指導の採用を黙って変えない。

修正した内部の不整合：

- 作戦の時間欄がセット数を返していた箇所を実所要時間へ変更。
- 基本候補が手動で選んだ目的を次回に置き換える問題を修正。
- 「相談して決める」の目的を期間内で解決した後、その解決値が永続化して減量を続ける問題を修正。期間内の目的は固定し、期間末に合意した相談方針へ戻す。手動の増量/減量はそのまま保持する。
- 大会日の仕事時間・参加/遠征費をプレイヤーとライバルへ反映。
- 最終回の大会日、結果→エンディング、国内結果の固定を明確化。
- 期間途中の保存、二重確定、別タブ更新、保存失敗時の巻き戻しを実装。

食事は設定済みと充足を分け、目標/実際のエネルギーとたんぱく質、不足理由、食品の要約、準備時間、実費を表示する。実UIで手軽な食事1200円の不足から1600円への変更を比較し、栄養充足と期間収支の低下を確認した。数値指定は食品の献立と区別する。不足を隠して必ず筋肉が増えるようにはしていない。

## 大会・ライバル・記録

小規模5人、地域7人、地方9人、全国11人、世界9人の架空体系。地方への複数出場実績など、優勝以外の出場経路を持つ。世界は国内上位実績と前半20回の経過が条件。費用・移動費・当日の使用時間は確定前に表示する。

12人の固定名ライバルは固有の初期体格、成長余地、得意分野、技術、生活と同じ日次計算を持つ。対戦履歴と現在の身体を記録し、敗北に応じた隠れた強さ補正を掛けない。各会場の資格を取得済みの相手として登場する設定であり、画面外の全資格取得過程まで計算してはいない。

受付・計量・登場・正面/背面のポーズ・順位発表を短くつなぎ、停止/再生/省略を用意。通常ジムと大会会場を分け、出場番号と大会衣装を反映する。記念は実データから作るSVG結果カードで、撮影写真ではない。

結果は順位、強み、課題、直上相手との配点込みの差を先に示し、式は折り畳む。仕上がり100は既存の架空審査で体脂肪12〜22%に入ったことを意味し、現実の大会レベルの絞りを保証しない。総合点の15点分であることを説明する。最低点と最も差がついた評価軸が異なる場合も分ける。

20/40回の課題、候補、確定案、期間、身体/技術、収支、出来事、結果を保存。全身の推移を先に示し、部位別へ進める。グラフは決断・章・大会、日付と単位を関連づけ、0からの全体表示と縦軸を明記した詳細表示を切り替える。エンディングは初日/最後、最初/最後の大会、伸びた部位、技術、資金、選んだ作戦と対戦履歴から作る。

## 保存と互換性

従来 `bulk-life-v1` は維持。挑戦は別DB `bulk-life-challenges-v1`、形式 `BULK_CHALLENGE` version1、計算 `decisions-1`。旧キャリアを暗黙移行せず、従来キャリアとして開ける。日次画面を使って挑戦の回数を回避する経路はない。

確定作戦、決断番号、初期seed、身体/生活/資格、ライバル、乱数、実行識別子、終了日、現在の計算位置を保存。7日以内のバッチごとにrevisionの比較と更新を同一トランザクションで確定し、保存前のUIを成功状態へ進めない。中断後は保存済み境界から同じ期間を再開する。

JSON読込は検証後に別IDのコピーへ追加し、既存記録を上書きしない。新フィールドの実施種目サンプル/最終更新日時/作成時のモデル版は省略された旧挑戦ファイルにも対応。未記録の表示版はその旨を表示し、同条件比較のseed・計算版と区別する。国内20回の終了データは世界編へ進んでも固定する。端末・ブラウザ・URLで保存が分かれ、クラウド共有はない。

## 人物改善が小さく見えた原因と今回の反映

旧参照の調査で、互換モデル名 `athlete-v2` と実際に配信するv5ファイルの名前が異なり、制作対象を名前だけで判断できなかった。今回は `portraitAsset.ts` → `/assets/athlete-v6.glb?revision=8e81d79dd2aa` を実ブラウザの開発表示で確認した。タイトル・ホーム・身体詳細・大会・比較は同じ読み込み処理を使う。意図的な読込失敗では旧モデルへ黙って戻らず、代替表示と再読込を出す。

前回の差が小さかった要因は、元の広い領域の膨張を残したまま小さな修正を重ねた体型、ビジネスシャツ由来の襟形状、服に不足した腕上げ補正、輪郭を硬くする髪のアルファ閾値、床の下に隠れた接地影だった。キャッシュが原因で全画面が古いモデルを表示していたと断定できる証拠はなく、そのようには報告しない。

ライブBlender連携はタイムアウトした。接続・編集できたと偽らず、インストール済み公式Blenderのバックグラウンド実行で、v5を複製した **`assets/blender/bulk-life-athlete-v6-work.blend`** を実際に編集・保存・書出・再読込・描画した。v2〜v5の制作ファイル/ゲーム資産は変更していない。元CC0素材の来歴と22ファイルのハッシュを検証し、新規購入はない。

実際の修正：

- 一体の皮膚と骨格を維持し、筋量の基準形を16領域で分配。胸/肩/腕/脚の変形が同じ領域へ重複加算される膨張を抑制した。
- 胸郭側374頂点の腕ウェイト、腕上げ時の肩・胸・脇の補正、左右の肘曲げ専用補正を調整。元の関節位置を保つ。
- 顎、口元、眼周辺、鎖骨の形はミリ単位で調整した。顔全体が別品質へ作り直されたと評価できる差ではない。
- 短髪の頭頂/こめかみ/襟足とカード輪郭を調整。ブラウザの透過閾値を0.4→0.18にして薄い毛先を残した。近接の毛束表現は未達。
- タンクを実際の曲線で切り直し、丸首、袖ぐり、薄い縁、体型/座位/腕上げへの追従を作成。元の襟フラップを除去した。裾と肩縁にはまだ波打ち/角張りが残る。
- 肌の独立した色テクスチャと脚の色の強さ、粗さと法線を調整。顔・脚の色の差を弱めた。肌細部だけで形を隠さない。
- 靴と裸足の足元を分け、接地影を床の上へ戻した。これは陰影の改善であり、人体造形の改善とは区別する。
- 座位の左右の手・前腕と指の既存修正を引き継いだ。標準/高脂肪の座位を確認したが、全体型・全動作の完全な接触保証はない。

## 自動検証と面白さの区別

`npm.cmd test` は113件成功。保存障害、従来計算/移行、新モード最初の4回、コーチ/手動、無料編集、6抽選などを含む。型検査と本番ビルド成功。長期の6パターン×40回、直接世界40と国内20+追加20の全期間同一性、3初期条件×5方針の差、合法な世界優勝例を専用スクリプトで検証する。詳細は同ディレクトリのJSONを参照。

多く働けば資金は増えるが時間と競技点は下がり、大きな練習量は少し筋量を増やしても技術/状態と順位で劣る例がある。高額の食事も全員の優勝を保証しない。出場しない方針は実際に未出場の終了結果となる。有限の方針サンプルであり、あらゆる最適解の不存在を証明してはいない。

同じP2・seed823を40回進めた計算例では、基本方針の総合88.68点/資金約504万円に対し、練習量重視は75.87点/約610万円、仕事重視は79.80点/約928万円、高額食事は89.02点/約260万円だった。筋量・技術・資金が同じ方向へ一律に増える調整にはしていない。15本すべての期間計算で記録された栄養不足日は0だったが、手動不足案のテストでは不足が実際に記録される。

相談目的が減量へ固定される修正前のP5・未出場方針は、長期で体脂肪約3.84%まで下がる例があった。同じ初期条件の修正後は約18.99%となり、相談の再評価が継続することを確認した。明示的に減量を続ける作戦とは区別する。

実UIの2選手完走で、再挑戦、予算変更、優勝/未優勝、身体と履歴のつながりを確認した。一方で、初見の人の理解・選手への愛着・周回の面白さの評価はユーザーテストが必要。自動テストをその代わりとはしない。

```powershell

```

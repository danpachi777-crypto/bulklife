# 計算の仮定 v0.2

研究の影響方向、公式規則、ゲーム係数を分ける。数値は医学的測定・将来予測ではない。確認範囲はscience-research.md、competition-research.md、food-sources.mdを参照。

- 体重は16部位筋質量、脂肪、その他除脂肪組織、短期水分差の和。初期筋質量は除脂肪組織の48%というゲーム仮定。初期生成後はprofileIdで成長・順位を変えない。
- 24種目の直接/間接刺激、重量、回数、RIR、フォーム、設備、時間帯からセット実績を計算。逓減刺激、疲労、回復、発達余地、年齢で更新。能力、パンプ、筋質量は別状態。
- 前夜の睡眠を当日の回復に使う。起床7時・勤務9時、往復通勤、移動、調理、身支度、ポージング、有酸素を24時間内で計上し、予定より実行できなかった理由を記録。
- 30食品は調理状態付き文科省成分値。食品と量から栄養・費用・準備時間を算出し、資金不足時は摂取量を減らす。水分・栄養充足・空腹の係数はゲーム設定。
- 収入・固定費・ジムは月額を暦月日数で日割り計上。仕事変更は元の雇用条件から再計算。給与日別の資金繰りは未対応。
- 大会は年度資格、有効期間、期限、別途承認、費用、遠征、当日の体重、審査を順番に判定。NPC参加実績、カード、プロ登録、契約、OQSを別状態にする。
- 審査は身体の筋量/身長、バランス、左右差、仕上がり、ポーズから算出。ラウンド方式と内部能力係数を区別。内部係数・選考閾値・日程・費用はゲーム設定。固定のプロフィール順位上限や勝利保証はない。
- CPUは独立した選手と乱数系列を持ち、年次成長・引退・新世代を保持。プレイヤーに合わせて弱くしない。
- 大会後21日間の回復では最初7日、次14日で練習時間上限を段階的に戻す。世界タイトルは後の敗戦で消えない。
- 週次・節目送りも同じ日次処理を繰り返し、重要な遠征・大会・意思決定で停止。引退後は更新を止め記録を残す。

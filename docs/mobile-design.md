## 操作と表示

- 上部は名前、週と曜日、目標、ゲーム日付、所持金。知識・設定はヘッダー内へ置き、スクロール中の内容に浮かせない。

- 詳細3Dは通常、縦スワイプでスクロールする。回転ボタンを有効にした時だけOrbitControlsへジェスチャーを渡す。Canvasだけでなく親のtouch-actionも切り替える。ドラッグ後のクリックで部位を誤選択しない。
- 今日の3行はおすすめ・設定済み・休養日・大会休養・回復期間を文字で表示。既存の計画と費用、短縮の注意を表示し、実行不可と助言を区別。
- 今日の実行は下部ナビの上。説明とセットで表示し、本文末尾に必要な余白を残す。結果の翌日ボタンも同じ位置。結果は実際の計算ログを使い、表示のために身体計算を変更しない。
- 編集は全画面パネル、保存・キャンセルを固定。元画面をinertにしてスクロールを固定し、終了時に位置とフォーカスを戻す。visualViewportの変化へ追従し、ソフトキーボード中は背後の固定ナビ/日次ボタンを隠す。
- 週間計画は各日の要約を開いて編集。今日の曜日を最初に開く。PCは従来の一覧を維持。
- 確定した設定と進行は既存のIndexedDBトランザクションで保存する。終了イベントへの保存依存を追加しない。既存の連打防止ref/disabledを維持する。

## 描画

ホームの3Dは静止・軽量。詳細はスマホ幅で軽量を初期値にし、品質の手動選択を端末へ保存。表示中の動作はスマホ幅で30回/秒の描画要求とし、画面外/非表示タブでは描画ループを止める。回転等の操作による追加フレームは発生する。これは実機で30FPSを保証したという測定値ではない。動きを減らすOS設定を尊重する。

GLBの読み込み失敗に加え、遅延JSモジュールの失敗も局所的な代替表示へ分け、今日の操作を残す。動作を止めた初期表示にもクリップの0時点を適用し、Aポーズのまま残さない。身体形状の頂点や骨格は変更しない。

## Wi-Fiと保存先

`npm.cmd run dev:lan` と `npm.cmd run lan:url` を用意。今回のWi-Fi IPv4は `192.168.2.197`、ゲームは `http://192.168.2.197:5178/`。同一Wi-FiでPCとサーバーを起動したまま使う。ルーターの端末間隔離やファイアウォールによる拒否まではPC内の疎通確認から断定できない。Windowsのセキュリティ設定は変更していない。

HTTPのLANでも作成/復元できるよう、secure contextに限定されるrandomUUIDの直接呼出しをgetRandomValuesによる同形式のUUIDへ置換した。IndexedDBの保存形式は同じ。IPやlocalhost、127.0.0.1、公開URL、スマホのブラウザーごとのデータは別であり、JSONで移す。自動共有はない。

## PWAと更新

Manifest、オリジナルのBLアイコン192/512/maskable512、Apple touch icon、テーマ色、standaloneを追加。外部Webフォント依存を除いた。初回に21ファイル・約15.4MBの本体/モデル/背景/器具を版ごとに一括キャッシュする。初回準備後はローカルの育成・大会・記録・3Dをオフラインで使える。外部の出典リンクは対象外。

更新のinstallが完了しても自動で版を切り替えない。画面の「保存して更新」で最新の状態を保存し、待機Workerを有効化して再読込する。新しい版を準備できない場合は以前の版を維持する。削除するのは同ゲームの古いキャッシュだけで、IndexedDBのセーブは削除しない。サブディレクトリ配信は未設定のため、現在のビルドはURLルートへの配置が必要。

Service WorkerはHTTPS（またはPCのlocalhost検証）で利用する。Wi-FiのHTTPにオフライン起動を案内しない。[MDNのService Worker条件](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)。iPhoneは[Safariの共有からホーム画面へ追加](https://support.apple.com/en-az/guide/iphone/iphea86e5236/26/ios/26)、対応Chromeはインストールメニューを使う。

既存のSites一覧とGitHub Pages設定を調べ、BULK LIFEの公開済み配信先は確認できなかった。新しいHTTPS配信はユーザーへ具体的に確認してから行う。ローカルビルドとプレビューは先に準備する。
